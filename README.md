# APEN

Repository for the **APEN** AI conversational agent project (reception, appointment booking, transfer, callback summaries). 

| Item | Description |
|------|-------------|
| **apen-agent-mvp/** | MVP backend + web app: intent, calendar, summaries, Vapi webhook. Run with `./run.sh` or see [apen-agent-mvp/README.md](apen-agent-mvp/README.md). |
| **Feasibility-Study-AI-Conversational-Agent-APEN.md** | Feasibility study (objectives, scope, plan). |
| **Etude-faisabilite-Agent-IA-conversationnel-APEN.md** | French version of the feasibility study. |

## Quick start (MVP)

```bash
cd apen-agent-mvp
./run.sh
# Open http://localhost:8000/
```

See [apen-agent-mvp/DELIVER-AND-SHOW-MVP.md](apen-agent-mvp/DELIVER-AND-SHOW-MVP.md) for delivering and showing the MVP.
