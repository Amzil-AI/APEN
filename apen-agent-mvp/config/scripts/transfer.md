# Transfer script – APEN

**Version:** 1.0 – MVP

---

## Before transfer

- Repeat intent: "Je comprends que vous avez une demande [urgence / SAV / partenaire]. Je vous transfère vers [service]."
- Optional: "Un conseiller va vous répondre sous peu. Merci de rester en ligne."

---

## Fallback if transfer fails

- "Le service est momentanément indisponible. Je note vos coordonnées et le motif de votre appel pour un rappel dans les plus brefs délais. Puis-je avoir votre nom et votre numéro ?"
