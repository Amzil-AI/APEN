Pipeline MVP : prise d’appel → intention → action

Flux réel : appel entrant, qualification, puis book / transfert / synthèse rappel.

  1. Prendre l’appel — Réception 24/7 (Vapi ou autre).
  2. Accueillir — Dire l’accroche (GET /voice/prompt).
  3. Récupérer la demande — Parole → texte (STT) → transcript envoyé à l’API.
  4. Vérifier l’intention — RDV, info, urgence, SAV, partenaire, autre (intents.yaml).
  5. Décider l’action — book_appointment, transfer, ou collect_summary.
  6. Agir — Proposer créneaux + créer RDV · ou transférer vers le bon numéro · ou enregistrer une synthèse rappel.

Donc : Appel → Accueil → Parole (transcript) → Intent → Action → Book / Transfert / Rappel.
